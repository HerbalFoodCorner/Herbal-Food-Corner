PUBLISH කරන ආකාරය
------------------
1. GitHub account එකට login වෙන්න.
2. Repository එක open කරන්න:
   https://github.com/asankanammuni/Herbal-Food
3. දැනට තිබෙන files backup එකක් ලෙස download කරගන්න.
4. මෙම ZIP එක extract කරන්න.
5. ZIP එකේ ඇතුළත files සියල්ල repository එකේ root folder එකට upload කරන්න.
6. Existing index.html සහ styles.css replace කරන්න.
7. Commit changes කරන්න.
8. Repository Settings > Pages වෙත යන්න.
9. Deploy from a branch > main > /(root) තෝරා Save කරන්න (දැනට Pages enabled නම් ඒ setting එක තබන්න).
10. Website එක publish වූ පසු පරීක්ෂා කරන්න:
    https://asankanammuni.github.io/Herbal-Food/
